# Release Guide — AVIA Museum (iOS)

(Note: `README.md` in this folder is auto-generated by fastlane on every run —
this file is the real guide.)

The fastlane setup pushes App Store **metadata, screenshots, pricing, and App
Review info** to App Store Connect. The **binary is NOT uploaded by
fastlane** — you archive and upload it yourself (see below).

## One-time setup

1. **API key**: `AuthKey_ZW7RMV5D95.p8` must sit in this `fastlane/` folder
   (it's already here). It is **git-ignored** — never commit it, never share
   it. If it ever leaks, revoke it in App Store Connect → Users and Access →
   Integrations.
2. The app entry must exist in App Store Connect with bundle id
   `com.alexli.aviamuseum`.

## Usage

```sh
cd /Users/terrorbyte/Documents/GitHub/Aviation-Museum
fastlane ios upload_metadata
```

This uploads:
- everything under `fastlane/metadata/` (name, subtitle, description,
  keywords, promo text, release notes, support URL, copyright, categories,
  App Review contact info + reviewer notes)
- screenshots from `screenshots/en-US/` (deliver requires a locale subfolder
  and tells iPhone from iPad by image resolution — the `iphone69_`/`ipad13_`
  filename prefixes are for humans; the `01_`–`05_` numbers set store order)

Pricing is NOT uploaded: Apple removed the API endpoints deliver used for
`price_tier`, so set the price once by hand (see manual checklist below).

The app version is **not** hardcoded anywhere in `metadata/` — deliver
attaches the metadata to the editable version created when you upload a build.

## Uploading the binary (manual, by you)

1. Open the project in **Unity 6000.3.6f1**, run **File → Build Profiles →
   iOS → Build** (or `BuildIOS.BuildDevice` from the command line) to generate
   the Xcode project into `Builds/iOS`.
2. Open `Builds/iOS/Unity-iPhone.xcodeproj` in Xcode → select "Any iOS Device"
   → Product → Archive → Distribute App → App Store Connect.
   Signing is already configured for team `63R7WU94A2` with automatic signing.
3. `ITSAppUsesNonExemptEncryption = NO` is stamped into the Info.plist by
   `Assets/Editor/IOSPostProcess.cs` (standard-HTTPS-only exemption), so the
   export-compliance question is answered automatically.

## Apple requirements before you can submit

Handled by this fastlane setup:
- ✅ Name, subtitle, description, keywords, promo text, release notes
- ✅ Support URL, copyright, categories (Education / Reference)
- ✅ App Review contact (Jonathan Sahagun) + "no sign-in required" note
- ✅ iPhone 6.9" + iPad 13" screenshots
- ✅ Export compliance (via Info.plist key)
- ✅ Content rights: declares no third-party content
- ✅ 1024×1024 App Store icon (generated by Unity from the project icon)

Manual, in App Store Connect (worksheets in `APP_STORE_CONNECT_WORKSHEETS.md`):
- ⬜ App Privacy labels (answers prepared in the worksheet)
- ⬜ Age rating questionnaire (answers prepared in the worksheet)
- ⬜ Privacy Policy URL (you said you'd set this yourself)
- ⬜ Set price to Free: Distribution → Pricing and Availability → 0 USD
  (the API no longer supports setting prices; one-time step)
- ⬜ Verify availability = all countries (API can't set it; default is all)
